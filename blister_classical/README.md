Blister Classical
(explores multi-cavity industrial inspection (5x6 blister packs) using pure OpenCV math)

Concepts Covered:
1. Grid-Mapping Loops: Automatically partitioning total bounding boxes into structured rows and columns.
2. HSV Color Masking: Separating hue from brightness to handle lighting variations.
3. Brightness Variance Analysis: Using pixel intensity distribution to detect texture changes.
4. The Glare Limitation: Documenting why specular highlights and reflections on aluminum foil break classical mathematical thresholds.
