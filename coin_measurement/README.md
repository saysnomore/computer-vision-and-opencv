Classical Computer Vision & Spatial Calibration
(demonstrates foundational image processing using OpenCV to measure real-world objects from digital photos)

Concepts Covered:
1. Gaussian Blur & Canny Edge Detection: Noise reduction and boundary extraction.
2. Spatial Calibration: Using a physical reference object (coin) with a known diameter to calculate a `pixels_per_mm` scale factor.
3. Mathematical Tolerance Logic: Evaluating absolute differences to flag manufacturing defects programmatically.
